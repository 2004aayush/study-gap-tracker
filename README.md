# Study Gap Tracker

This is a simple Python project I built to track my daily study hours and check if I'm being consistent or not.

## What it does
- Lets you add how many hours you studied each day
- Shows all your past records
- Detects gaps if you skip studying for days
- Calculates total study time for recent days
- Finds the day you studied the most

## How it works
The program stores data in a text file and uses basic Python logic to analyze dates and study patterns.

## What I learned
- File handling in Python
- Working with dates using datetime
- Basic logic building and structuring a CLI program
